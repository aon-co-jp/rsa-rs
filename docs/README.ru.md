# rsa-rs (Русский)

> ⚠️ **Машинный перевод ИИ — не проверен носителями языка.** Основными являются японский/английский [README](../README.md).
> ⚠️ **Экспериментальный проект. Криптографический аудит третьей стороной не проводился.** Постоянство времени выполнения проверено лишь выборочно и не доказано.

**Кратко:** `rsa-rs` — совместимая замена той части Rust-крейта `rsa`, которую используют `ssh-key`/`russh` (подписи PKCS#1 v1.5) и `sqlx-mysql`
(только шифрование OAEP открытым ключом). Цель — обойти RUSTSEC-2023-0071 (атака Marvin), для которого нет исправленной версии `rsa`.
Написано по RFC 8017; на crates.io не публикуется.

## Структура
* `core/` — ядро (RSADP со слепотой (blinding) + CRT + проверка результата, подпись PKCS#1 v1.5, OAEP, генерация ключей).
* `compat-0.10/` — крейт `rsa` 0.10.0-rc.18 (для `ssh-key`, `russh`). `compat-0.9/` — крейт `rsa` 0.9.10 (только открытый ключ + OAEP, для `sqlx-mysql`).

## Использование
```toml
[patch.crates-io]
rsa = { path = "../rsa-rs/compat-0.10" }
rsa-090 = { package = "rsa", path = "../rsa-rs/compat-0.9" }
```
Требуется `crypto-bigint >= 0.7.10` (`cargo update -p crypto-bigint --precise 0.7.10`). См. [PORTING.md](../PORTING.md).

## Меры защиты
Постоянное ослепление (blinding); проверка результата CRT (при сбое значение не возвращается); проверка подписи повторным кодированием и сравнением;
декодирование OAEP без ветвлений и с единственным типом ошибки; **нет** расшифрования PKCS#1 v1.5 (исчезает поверхность атак Bleichenbacher/Marvin); обнуление секретов.

## Проверки
Тесты с известными ответами (OpenSSL, побайтно совпадающие подписи; RFC 8017 §9.2), **Wycheproof** (проверка подписи RSA и OAEP), собственные тесты `ssh-key`,
`ssh-keygen -Y sign/verify` в обе стороны, расшифрование наших шифртекстов OAEP через `openssl`, сборка `sqlx-mysql` 0.8.6 и `russh` 0.63 (open-web-server).

## Ограничения
Нет внешнего аудита; нет проверки на уровне инструкций (дизассемблирование); измерение времени — только простой t-тест; PSS, шифрование PKCS#1 v1.5, multi-prime, serde не реализованы; проверено только на Linux/WSL.
